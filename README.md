# 太陽系撞球

把「太陽系模型」變成 8-ball 風格的太空撞球：十五顆天體就是十五顆球，太陽是 8 號黑球，母球是白色冰晶彗星，袋口是黑洞，球檯是半透明藍色玻璃框，背景是宇宙。

## 玩法
- 類地組 1–7（水星、金星、地球、火星、月球、木衛一、木衛二）對類木組 9–15（木星、土星、天王星、海王星、冥王星、木衛三、木衛四）。開球後第一顆合法進袋的球決定組別。
- 先打光自己組別，再打進太陽（8 號）獲勝；太陽太早落袋、或打太陽時犯規直接判負。
- 犯規（母球落袋、沒碰到球、先碰到對方組或太陽、擊球後沒有球碰邊襯）：對手獲得自由球。
- **瞄準**：點擊球檯設定方向（瞄準固定，不會跟著滑鼠跑）；拖曳瞄準光環，或用 ←/→ 鍵微調。
- **力道**：左側垂直力道條，抓住圓鈕往下拉，放開就擊球（也可按住空白鍵蓄力、放開擊球）。自由球時右側會出現「放置母球」鈕。
- **加塞**：右側圓盤，往上＝跟球，往下＝縮球，左右＝邊塞（簡化模型，電腦不使用）。雙擊歸零。
- **特效**：太陽被撞會噴岩漿，天王星／海王星是海浪，木星是風暴漩渦，土星是光環震波，地球是極光與雲，火星是沙塵，金星是酸霧閃電，冥王星是冰晶。水星、月球和四顆衛星沒有特效。
- **鏡頭**：預設完整俯瞰整張球檯。拖曳空白處旋轉，滾輪／雙指縮放，右鍵拖曳平移，「全景」復位，「全螢幕」切換全螢幕。沒有暫停功能；「主選單」會放棄本局。

## 本機執行
直接用瀏覽器開 `index.html` 即可（需 WebGL2）。若瀏覽器限制本機檔案，改用：`python3 -m http.server 8000` 後開 `http://localhost:8000`。網址加 `#debug` 會開放 `window.__dbg` 供測試。

## 部署到 GitHub Pages
1. 把整個資料夾推到 GitHub 儲存庫的 `main`。
2. Settings → Pages → Source 選「GitHub Actions」（已附 `pages.yml`），或選 Branch: main / root。
3. 完成後網址為 `https://<帳號>.github.io/<儲存庫>/`。所有路徑都是相對路徑，子目錄部署可用。

## 與規格的差異（請看）
- **沒有使用 three.js。** 開發環境無法連到 CDN／npm，three.js 無法在其中測試，所以自寫了迷你 WebGL2 引擎來渲染；原模型的著色器與貼圖是原樣沿用，但場景結構是自己的。若你一定要 three.js，需要在可連網的環境重做渲染層，物理／規則／AI 可沿用。
